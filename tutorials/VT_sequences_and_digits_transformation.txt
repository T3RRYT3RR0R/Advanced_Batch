VT escape character 0x1b is defined in :Setup using
  for /f "Delims=" %%e in ('Echo Prompt $E^|%comspec%') Do Set "\E=%%e"
  %comspec% is a system variable initiated as the fully qualified filepath for cmd.exe
  Prompt $E sets the prompt to 0x1B
  This command is piped to cmd.exe and the command output is captured using the for loop.

REM data structures for displaying characters '1'~'9' and ':', with # replaced with literal value for 1~9
  %= move cursor to next X   =% Set ".=%\E%8%\E%[B%\E%7"

  %\E%8   - restore cursor position from memory
  %\E%[nB - move cursor n rows down in current column. Default is 1 if n absent
  %\E%8   - save cursor position to memory
  
  NOTE: cursor cannot be moved outside window buffer using VT sequences

Positional VT sequences:
         %\E%[A
           ▲

%\E%[D  ◄     ► %\E%[C
           
           ▼
         %\E%[B

  %\E%[H = 1;1 ScreenHome
  %\E%[y;xH = Cursor to Row Y column X
  %\E%[nd = move Cursor to    Row n - Defaults to 1 if n absent
  %\E%[nG = move Cursor to Column n - Defaults to 1 if n absent
  %\E%[nE = emit n newlines         - Defaults to 1 if n absent

The following is a parsing of the time variables content after delimiters have been stripped.
this is subsequently tokenised by For, with clock digits occupying tokens 1-8. The use of %%1
as the initial reference metavariable allows each number to correspond to the digits position,
with string substitutions search=replace used to transform each digits # to the current number.

A dummy token is used to consume token 9, in order to allow the use of the for metavariable %%:
to expand the delimiter of HH : MM : SS : CS from the _Int pseudo array
  - For metavariable order is aligned with printable Ascii characters 33~126
  RESOURCE: https://www.ascii-code.com/
 
  Set "t=!t:~0,1! !t:~1,1! !t:~2,1! !t:~3,1! !t:~4,1! !t:~5,1! !t:~6,1! !t:~7,1! RESERVED !_step!"
